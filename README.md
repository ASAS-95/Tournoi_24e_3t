# Tournoi FC Montmorency — version avec paramètres regroupés

Sections de paramètres : Terrain, Durée, Pause, Rotation, Format de la Finale, Début du tournoi.

Le nombre de terrains peut être fixé à 1 (pour le futsal), avec 1 terrain affecté au type synthétique pour respecter la contrainte technique de la ligue OR. Le type « salle » n’est pas encore géré.

Attention : avec un seul terrain et 16 équipes, le tournoi peut se prolonger tard. Le format de phases finales reste par tableaux de 8 équipes.

Pour installer : remplacer index.html et logo-montmorency.png à la racine du dépôt GitHub, puis attendre le déploiement Vercel. Exporter une sauvegarde JSON avant tout changement de configuration.
