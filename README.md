# Tournoi personnalisable — V4

Déployer `index.html` et `logo-montmorency.png` à la racine du dépôt GitHub existant.

Paramètres : équipes (8/16/24/32), terrains (2–12 dont au moins deux synthétiques), journées, durées, finale 1 ou 2 périodes, pause déjeuner, rotations et repos. Le planning est recalculé automatiquement.

IMPORTANT : exportez un JSON avant modification structurelle. Les données restent locales à chaque navigateur. Les horaires sont des prévisions et n’incluent pas l’attente aux tirs au but. Testez le déroulement avant utilisation officielle.
