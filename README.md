# FC Montmorency — Tournoi U12 (V2)

Application statique : déposer `index.html` et `logo-montmorency.png` à la racine du dépôt GitHub. Vercel déploie automatiquement.

## Fonctions
- 24 équipes et logos personnalisés (stockés localement)
- 5 journées avec adversaires de niveau proche, sans rencontre répétée
- 6 aires : Synthé 1/2, Herbe 3/4/5/6 ; synthé prioritaire aux deux premiers
- Phase finale à 8, scores et classement
- Nom du tournoi modifiable
- Export/import JSON pour sauvegarder, transférer et restaurer les données

## Important
Les données ne sont pas synchronisées entre appareils. Exporter le JSON régulièrement. Le site doit être ouvert en ligne ; hors-ligne après fermeture non garanti.
