# FC Montmorency — V7

Cette version reprend tous les fichiers de la V6 corrigée et améliore uniquement l’affichage public `direct.html`.

## Correctifs
- Texte sombre sur les légendes claires du plan, y compris en mode télévision.
- Liens de terrains contrastés en mode télévision.
- Bouton permanent « Quitter le mode TV » en haut à droite.
- Touche Échap pour sortir du mode télévision.
- Synchronisation du paramètre `?tv=1` dans l’adresse quand on active/désactive le mode télévision.

## Installation
Décompresser l’archive et remplacer les fichiers correspondants sur GitHub, puis valider le commit. Il suffit de remplacer `direct.html` pour ces correctifs ; les autres fichiers sont fournis pour conserver une archive complète.

La configuration Supabase existante est conservée. Aucun changement SQL.
